01 / ARCHITECTURE

Embedded Software Library

Runs in host firmware that supplies tri-axial sample batches. Sensor drivers, acquisition timing, and any external hardware are outside the library.

02 / LOCAL REACTION

Software Alert Latch

Sets a software alert after six consecutive threshold-exceeding evaluations. At 500 Hz with one 32-sample batch every 64 ms, six calls span 384 ms from the first qualifying call to the sixth. The host decides any response.

03 / ISOLATION

100% Air-Gapped & Offline

Deterministic fixed-point arithmetic with zero Wi-Fi/cellular reliance, zero IT firewall disputes, and zero recurring cloud subscriptions.
